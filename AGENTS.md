# Diretrizes do Projeto SoftBarber (AGENTS.md)

## Metodologia Superpowers
Este projeto segue estritamente as convenções do framework **Superpowers**:
- Use `.agents/skills/using-superpowers/SKILL.md` como guia fundamental de fluxo de trabalho.
- Brainstorming inicial e especificações detalhadas antes do código (`.agents/skills/brainstorming/SKILL.md`).
- Planos de implementação estruturados (`.agents/skills/writing-plans/SKILL.md`).
- Desenvolvimento Orientado a Testes (TDD) irrestrito (`.agents/skills/test-driven-development/SKILL.md`).
- Verificação formal de funcionamento antes da conclusão (`.agents/skills/verification-before-completion/SKILL.md`).

## Regra de Repositório Git / GitHub
- **Repositório Oficial:** `SoftBarber` no GitHub.
- **Sincronização:** Todas as alterações realizadas no projeto devem ser salvas, comitadas de forma descritiva e enviadas (`git push`) para o repositório remoto `SoftBarber` no GitHub.
- Mantenha a branch principal (`main`) ou branches de feature sempre atualizadas e sincronizadas com a nuvem.
